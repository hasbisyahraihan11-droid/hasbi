# My Companion ♡ - Hasbi VTuber Web Project

Proyek web ini dirancang dengan struktur profesional terpisah:
- `index.html` (Struktur HTML murni)
- `style.css` (Tampilan visual & CSS)
- `script.js` (Logika interaksi & JavaScript)

## Cara Upload & Deploy ke GitHub Pages:
1. Extract file ZIP ini di komputer kamu.
2. Buka GitHub, buat **New Repository** (misal: `vtuber-hasbi`).
3. Upload seluruh file (`index.html`, `style.css`, `script.js`, `README.md`) ke repository tersebut.
4. Pergi ke **Settings** > **Pages** di repository kamu.
5. Pada bagian **Branch**, pilih `main` atau `master` lalu klik **Save**.
6. Website kamu bisa diakses langsung via link dari GitHub Pages!
